آموزش کامل CSS - Box Model و Border

مثال 1: حاشیه یکدست (Solid)

این جعبه یک حاشیه قرمز یکدست دارد.
border: 3px solid #e74c3c;

مثال 2: هر جهت با استایل متفاوت

این جعبه هر طرف حاشیه متفاوتی دارد.
بالا: نقطه‌چین آبی
راست: خط‌چین سبز
پایین: یکدست قرمز
چپ: دوخط نارنجی

مثال 3: فقط زیر خط دارد

این جعبه فقط زیر خط دارد.
border-bottom: 4px solid #3498db;

مثال 4: نمایش کامل Box Model

جعبه با Box Model

عرض محتوا: 300px
padding: 20px (همه‌جهت)
border: 5px (همه‌جهت)
margin: 30px (همه‌جهت)

اندازه کل: 350px × 200px

نکات مهم:

  • Box Model: هر المان یک جعبه است با margin, border, padding, content
  • Border: برای ایجاد حاشیه دور هر المان استفاده می‌شود
  • User Agent Styles: مرورگرها استایل‌های پیش‌فرض دارند که باید آن‌ها را بشناسید
  • اولویت استایل‌ها: Inline > Internal > External > User Agent
  • برای وسط‌چین کردن: از margin: 0 auto; استفاده کنید
