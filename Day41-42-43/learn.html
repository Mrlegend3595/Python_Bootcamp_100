📚 آموزش کامل HTML و CSS

این صفحه شامل آموزش جامع تمام مفاهیم پیه HTML و CSS با مثال‌های عملی و توضیحات کامل است.

🏗️ ساختار اصلی HTML

HTML مخفف HyperText Markup Language است و برای ساختاردهی صفحات وب استفاده می‌شود.

<!-- هر سند HTML با DOCTYPE شروع می‌شود -->
<!DOCTYPE html>
<html lang="fa">
  <head>
    <meta charset="UTF-8">
    <title>عنوان صفحه</title>
  </head>
  <body>
    <h1>سلام دنیا!</h1>
    <p>این یک پاراگراف است.</p>
  </body>
</html>
📌 نکات مهم:
  • <!DOCTYPE html> در خط اول قرار می‌گیرد
  • تمام تگ‌ها باید بسته شوند (<tag> و </tag>)
  • تگ‌های خالی مثل <br> و <img> نیازی به بسته شدن ندارند
  • <head> اطلاعات غیرقابل مشاهده و <body> محتوای قابل مشاهده را شامل می‌شود

🏷️ Meta Tags و SEO

Meta Tags اطلاعاتی درباره صفحه به مرورگر و موتورهای جستجو می‌دهند و در بخش <head> قرار می‌گیرند.

<!-- Meta Tags مهم -->
<meta charset="UTF-8"> <!-- پشتیبانی از همه زبان‌ها -->
<meta name="description" content="توضیحات صفحه">
<meta name="keywords" content="کلمات, کلیدی">
<meta name="author" content="نام نویسنده">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
⚠️ نکات مهم Meta Tags:
  • charset="UTF-8" برای پشتیبانی از فارسی ضروری است
  • description حداکثر ۱۶۰ کاراکتر برای نمایش در گوگل
  • viewport برای طراحی واکنش‌گرا (ریسپانسیو) الزامی است
  • keywords امروزه اهمیت کمتری دارد اما همچنان مفید است

📦 Box Model (مدل جعبه)

Box Model مفهومی است که می‌گوید هر عنصر HTML مانند یک جعبه است که از ۴ بخش تشکیل می‌شود:

🔲 MARGIN (فاصله خارجی)
🟦 BORDER (حاشیه)
🟩 PADDING (فاصله داخلی)
📄 CONTENT
(محتوای اصلی)

🔲 MARGIN

فاصله خارجی - بین این جعبه و جعبه‌های دیگر

مثال: margin: 20px;

🟦 BORDER

خط دور جعبه

مثال: border: 3px solid red;

🟩 PADDING

فاصله داخلی - بین محتوا و حاشیه

مثال: padding: 15px;

📄 CONTENT

محتوای اصلی (متن، عکس، و...)

محتوای واقعی عنصر

🧮 فرمول محاسبه اندازه کل جعبه:
عرض کل = width + padding-left + padding-right + border-left + border-right
ارتفاع کل = height + padding-top + padding-bottom + border-top + border-bottom

🔧 box-sizing: border-box

box-sizing: border-box باعث می‌شود padding و border درون width و height محاسبه شوند.

بدون box-sizing:
عرض = ۲۰۰ + ۴۰ + ۱۰ = ۲۵۰px
با box-sizing: border-box:
عرض = ۲۰۰px (همان width)

🖍️ Border (حاشیه) - آموزش کامل

BORDER خطی است که دور هر عنصر کشیده می‌شود و دارای ۳ ویژگی اصلی است:

  • border-width - ضخامت حاشیه
  • border-style - نوع خط (یکدست، نقطه‌چین و...)
  • border-color - رنگ حاشیه

انواع border-style

solid
(یکدست)
dotted
(نقطه‌چین)
dashed
(خط‌چین)
double
(دو خط)
groove
(شیاردار)
ridge
(برجسته)
inset
(تو رفته)
outset
(برآمده)
none
(بدون حاشیه)
/* سینتکس کامل border */
/* 1. همه جهات با هم */
border: 3px solid #e74c3c;

/* 2. هر جهت جداگانه */
border-top: 5px dotted #3498db;
border-bottom: 7px dashed #2ecc71;

/* 3. تفکیک شده (ویژگی‌ها جدا) */
border-style: solid dotted dashed double; /* بالا راست پایین چپ */
border-width: 5px 3px 7px 2px;
border-color: #e74c3c #3498db #2ecc71 #f39c12;

جهت‌های مختلف border

border-top: فقط بالا خط دارد (۵px یکدست قرمز)
border-bottom: فقط پایین خط دارد (۵px یکدست آبی)
border-left: فقط چپ خط دارد (۵px یکدست سبز)
border-right: فقط راست خط دارد (۵px یکدست نارنجی)
ترکیبی: هر جهت استایل متفاوت
بالا: نقطه‌چین قرمز | راست: خط‌چین آبی | پایین: یکدست سبز | چپ: دوخط نارنجی

📏 Margin و Padding - آموزش کامل

MARGIN = فاصله خارجی (بین این عنصر و عناصر دیگر)

PADDING = فاصله داخلی (بین محتوا و حاشیه عنصر)

مثال MARGIN
جعبه زرد = فضای خارجی
محتوای با margin: 30px
(فاصله از بیرون)
مثال PADDING
جعبه آبی = فضای داخلی
محتوای با padding: 30px
(فاصله از داخل)

روش‌های مقداردهی Margin و Padding

۱ مقدار: همه جهات یکسان
margin: 30px; padding: 30px;
۲ مقدار: بالا/پایین و چپ/راست
margin: 20px 40px; padding: 20px 40px;
۳ مقدار: بالا، چپ/راست، پایین
margin: 10px 20px 30px; padding: 10px 20px 30px;
۴ مقدار: بالا، راست، پایین، چپ (ساعتگرد)
margin: 10px 20px 30px 40px; padding: 10px 20px 30px 40px;
📌 نکته مهم:

margin: 0 auto; برای وسط‌چین کردن افقی عناصر استفاده می‌شود.

مثال: div { width: 300px; margin: 0 auto; }

📝 تگ‌های Heading و پاراگراف

Heading (h1 تا h6) برای عناوین با سطوح مختلف استفاده می‌شود.

Paragraph (p) برای پاراگراف‌ها استفاده می‌شود.

h1 - عنوان اصلی

h2 - عنوان سطح ۲

h3 - عنوان سطح ۳

h4 - عنوان سطح ۴

h5 - عنوان سطح ۵
h6 - عنوان سطح ۶

p - پاراگراف معمولی

📌 نکات مهم Heading:
  • در هر صفحه فقط یک h1 استفاده کنید (برای سئو)
  • از h1 تا h6 به ترتیب استفاده کنید (پرش نکنید)
  • h1 بزرگترین و h6 کوچکترین هستند

💪 تگ‌های تاکید - em, strong, b, i

تفاوت اصلی در معنای سئو و دسترسی‌پذیری:

  • <b> = پررنگ (ظاهری)
  • <strong> = تاکید قوی (معنایی - برای سئو)
  • <i> = ایتالیک (ظاهری)
  • <em> = تاکید (معنایی - برای سئو)

b - متن پررنگ (ظاهری)

strong - متن پررنگ (معنایی - مهم)

i - متن ایتالیک (ظاهری)

em - متن ایتالیک (معنایی - تاکید)

strong + em - هم پررنگ و هم ایتالیک

📋 لیست‌ها - ul و ol

لیست نامرتب (ul)

  • مورد اول
  • مورد دوم
  • مورد سوم
  • مورد چهارم

لیست مرتب (ol)

  1. مرحله اول
  2. مرحله دوم
  3. مرحله سوم
  4. مرحله چهارم
📌 نکات مهم لیست‌ها:
  • ul برای لیست‌های بدون ترتیب (نشانگر نقطه‌ای)
  • ol برای لیست‌های با ترتیب (شماره‌دار)
  • list-style-type برای تغییر شکل نشانگر
  • لیست‌ها می‌توانند تو در تو باشند

📊 جداول - table

جدول برای نمایش داده‌های ساختاریافته در سطرها و ستون‌ها استفاده می‌شود.

بخش‌های اصلی: thead (سرستون)، tbody (بدنه)، tfoot (پاورقی)

# نام سمت سال
۱ علی محمدی توسعه‌دهنده ارشد ۱۴۰۲
۲ مریم حسینی طراح UI/UX ۱۴۰۳
۳ رضا کریمی مدیر پروژه ۱۴۰۱
مجموع: ۳ نفر
📌 نکات مهم جداول:
  • colspan برای ادغام ستون‌ها
  • rowspan برای ادغام سطرها
  • border-collapse: collapse برای حذف فاصله بین سلول‌ها

🔗 لینک‌ها - a

تگ a (anchor) برای ایجاد لینک به صفحات دیگر یا بخش‌های مختلف یک صفحه استفاده می‌شود.

🔗 گیت‌هاب (تب جدید) 🔝 بازگشت به بالا 📧 ایمیل 📞 تلفن ℹ️ لینک با عنوان
📌 نکات مهم لینک‌ها:
  • target="_blank": باز شدن در تب جدید
  • target="_self": باز شدن در همان تب (پیش‌فرض)
  • href="#id": رفتن به بخشی از صفحه
  • href="mailto:...": باز کردن ایمیل
  • href="tel:...": شماره‌گیری تلفن

🖼️ تصاویر - img

تگ img برای نمایش تصاویر استفاده می‌شود.

👤

تصویر گرد با border-radius: 50%

🌄

تصویر با گوشه‌های گرد

🖼️

تصویر با سایه (box-shadow)

<!-- استایل‌های مختلف تصویر -->
<img src="image.jpg" alt="توضیح تصویر">

/* گرد کردن تصویر */
border-radius: 50%; /* دایره */
border-radius: 15px; /* گوشه‌های گرد */
border: 5px solid #3498db; /* حاشیه */
box-shadow: 0 5px 20px rgba(0,0,0,0.2); /* سایه */

🏷️ کلاس‌ها (Class) و شناسه‌ها (ID)

کلاس (Class) - با . در CSS و class در HTML - قابل استفاده مجدد

شناسه (ID) - با # در CSS و id در HTML - یکتا و منحصر‌به‌فرد

این متن با کلاس highlight هایلایت شده
این متن با دو کلاس highlight و text-large
این جعبه با شناسه unique-box استایل داده شده
📌 تفاوت کلاس و شناسه:
  • کلاس: برای استایل‌دهی به چندین عنصر با ویژگی‌های مشترک
  • شناسه: برای یک عنصر خاص و منحصر‌به‌فرد
  • هر عنصر می‌تواند چند کلاس داشته باشد (با فاصله جدا می‌شوند)
  • اولویت استایل: ID > Class > Tag

معنی: فاصله داخلی
توضیح: فاصله بین محتوا و حاشیه عنصر

🖍️ BORDER
معنی: حاشیه
توضیح: خط دور عنصر

📐 WIDTH
معنی: عرض
توضیح: پهنای عنصر

📏 HEIGHT
معنی: ارتفاع
توضیح: بلندی عنصر

🎯 FLOAT
معنی: شناور

توضیح: متوقف کردن شناوری

معنی: پس‌زمینه

⚖️ قوانین اولویت در CSS

اولویت استایل‌ها در CSS:

  1. !important - بالاترین اولویت (کم استفاده کنید)
  2. Inline CSS - داخل تگ (style="...")
  3. ID - (#identifier)
  4. Class - (.class-name)
  5. Tag - (h1, p, div, ...)
  6. User Agent - استایل پیش‌فرض مرورگر
Tag - اولویت پایین
Class - اولویت متوسط
ID - اولویت بالا
Inline - اولویت بسیار بالا
